# Demonstration media

This directory is reserved for verified BlockMind screenshots, GIFs, and diagrams.

No demonstration media is included yet because the full Core ↔ Fabric ↔ Minecraft acceptance workflow has not been verified in a live world. Do not add mock gameplay imagery that could be mistaken for implemented behavior.

After live verification, useful demonstrations will include:

- autonomous house construction;
- navigation and recovery from an unreachable position;
- redstone or technical engineering;
- image/schematic reference reconstruction;
- validation, diagnosis, and self-repair.

Every gameplay asset should state the BlockMind commit, Minecraft version, relevant dependencies, test world conditions, and whether the run was fully autonomous or assisted.
